# 分组与筛选【分】：从几千篇到几十篇

> 钟澄《科研论》第六章（82–94）+ 第七章 96/99。术语：【分】/ 一次分组（粗分）/ 二次分组（细分）/ 三次分组 / 组集 / 非排他标签化 / 形成记录 / 中转组 / 逐一浏览。
> 案例数据：锂离子电池硅负极领域，6036 篇总文献 → 聚焦"碳包覆层形貌"。

---

## 0. 分组的目的是什么

> 目标是为了获得 idea，而不是说我们的目标是要将文献全部分组完毕。
> 类似这样的操作就完全又偏离"**以终为始**"了，变成**分类的目的就是分类**了。

分组服务于三件事：**开题、研究、写作**。

**鲸吞法的吞与吐**：

| 阶段 | 字诀 | 比喻 | 操作 | 判断重点 |
|---|---|---|---|---|
| 吞 | 【搜.鲸吞法】 | 把大小生物都吞进来 | 尽可能全面搜集，允许冗余 | **我感兴趣的文献有没有进来？** |
| 吐 | 【分】 | 鲸鱼吐海水，牙齿过滤 | 快速分组，筛出有价值的读 | 只进食需要的 |

> 鲸吞法的吞相当于构建文献库的过程，力求包含对你有参考价值的文献，哪怕冗余式的引入了不相关的文献；鲸吞法的吐相当于文献库的分组，从中找出确实有价值的文献进行阅读。

## 1. 一次分组（粗分）——了解领域全貌

对总文献库按标题特征词快速归类，形成一级分组。此时**还不需要特别考虑这个分组是否全面**。

**什么时候进入二次分组**：

> 等你对选题有个大概的方向，不再是完全不知道从事哪个细分领域后，就可以进行二次分组（细分）了，一次分组时还遗留下来的未分类文献也是在这一步处理的。

**俯瞰读法**：一级分组标签就是领域全貌的鸟瞰图——
- 按维度读：电池部件 / 硅基成分 / 制备方法 / 表征手段 / 性能 / 电池形态 / 理论方法；
- **从文献数量可知各研究方向的热度**；
- **标签提及的地方就是被人探索过的**；没被标签提及的、或标签之间的组合空缺，就是候选空间。

**一次分组的建组方式**：同类研究一般有共用特征词 → 用**搜索**快速分组。见 §5 检索词提炼规则。

## 2. 二次分组前的准备：先把"上一层级"搜全

### 2.1 删除测试法

> 通过对你研究中的一些词语的**删除测试**，你就能知道上一层级的研究是什么内容了，比如尝试删除"碳包覆层形貌"中的"形貌"，你知道显然不能删除"碳包覆层"，这个是你的研究对象。

想关注"碳包覆层**形貌**"→ 上一层级是"碳包覆层"→ 先把碳包覆层文献全部搜集齐全。

比喻（捕鱼）：

> 有的时候我们可能很难只钓到特定类型的鱼，所以我们通过**封闭鱼塘，然后抽水**的方式，将所有鱼都抓到，然后从中选出你要的鱼。

### 2.2 从"未分类"扫标题找新表达

案例：一次分组已有 `Carbon|C`、`Graphene`；从 498 篇"未分类"扫到 5 篇标题，获得 **CNT、-C、Graphite、CNF** 四个新表达。

原则：一次分组形成的分组**都来自总文献库**，文献是搜集齐全的，不用重搜；只从"未分类"继续找其他形式。

### 2.3 逐条在总文献库分组中检索

| 检索词 | 匹配方式 | 命中 | 去向 |
|---|---|---|---|
| `CNT` | 大小写匹配 | 101 | 新建"CNT" |
| `-C` | — | 466 | 快速扫一眼发现不相关 |
| `-C-` | — | 7 | 移入 `Carbon|C` |
| `C-` | — | 47 | 拖入 `Carbon|C`（其中 2 篇因 C-rate 误中但其余部分与碳相关，保留） |
| `Graphite` | 不匹配大小写 | 409 | 新建"Graphite" |
| `CNF` | 匹配大小写 | 21 | 新建"CNF" |

**中转组（去除组内不相关文献的标准手法）**：先建中转组 → 拖入全部结果 → 删去不相关（可"限定在中转组中的搜索"快速定位）→ 剩余拖到目标分组。不自信时再建一个中转组做二层检查。

### 2.4 建组集

新建组集（如"碳"）→ 把 5 个碳相关一级分组拖入 → 在组集下再建一个**同名大分组**"碳"，把 5 个分组的文献全部拖入（拖动而非移动）。

**搜索必须在"碳"分组而不是"碳-未分类"分组中进行**：

> 从"碳"分组搜，一篇文献可以再次被搜到并被贴上新标签；如果从"碳-未分类"搜，一旦被分组并从原分组去除，就再也没机会从未分类中找到这篇文献了。

### 2.5 分组中新建记录说明由来

> 考虑到时间久了，我们可能会忘记这个"碳"分组是怎么来的？因为光看名称无法快速了解（不可能是搜索碳获取的）。

分组中右键 → `New Reference` → Title 输入 `1-来自Carbon|C、CNF、CNT、Graphene、Graphite分组`。`1-` 前缀使其排在前列。形成过程复杂或非常重要的分组才做，不要频繁做。

## 3. 检索词提炼规则（8 条，核心可复现）

1. **少即是多 / 精简到最小单元**：inspired→inspire、Shaped→Shape、Rice Husks→Rice、pouch battery→pouch、All-Solid-State→solid。
   > 以上我们看到的单词虽然是 inspired、Shaped，但我们的搜索词是 inspire、Shape，还是基于"少即是多"原则，用这种方式 inspired 或 Shaped 的方式同样会被囊括在内，而且还有可能包含其他形式，如 shape 等。
2. **缩写/专有名词用大小写匹配**：SiC、3D、CNT、CNF、GO、SiO、P_。
   - 反例：搜 SiO 若不匹配大小写，"会出现文献标题中包含 dimensional 而被检索到的情况"。
3. **善用符号**：`_`=空格（`P_` 找磷，避免命中大写 P 开头的单词）、`-` 前/中/后缀（`-C`、`C-`、`Si-O`）、`/`（`Si/`）、`@`（`Si@` 核壳）、`|`（分组名中并列多个检索词）。
4. **删词测试**：删掉限定词，看能否囊括更多形式（`solid` 覆盖 All-Solid-State 的各种表达）。
5. **搜之前先想会不会太泛**：core/shell 太泛（搜 core、shell 会导致文献过多，区分度不够）；但 **like 太泛却恰好有用**（见 §4.3）。
6. **一次分组已搜过的词不再作为特征词**：carbon 本身在碳领域内不算特征词，**修饰 carbon 的单词**才算。
7. **检索词要能批量产出**：只能搜出一两篇的词留后处理。吃不准就先在"碳-未分类"中测试，效果理想后再到"碳"分组搜并建组。
8. **一篇文献可出现在多个分组**（非排他标签化，见 §7）。

## 4. 二次分组操作

### 4.1 从"父-未分类"逐篇提取特征词

按日期降序，从标题中找共用特征词。案例观察到的特征词与处理：

| 特征词 | 处理 |
|---|---|
| flexible（柔性的） | 搜 flexible → `碳+flexible` (66) |
| SiC | 大小写匹配 → `碳+SiC` (35) |
| three-dimensional / 3D | → `碳+three-dimensional\|3D` (137) |
| coralline-like | 去掉 like，只留 coralline → `碳+coralline` (1) |
| yolk-shell、nano、3D | → `碳+yolk-shell` (37)、`碳+nano` (1059) |
| porous | → `碳+porous` (319) |
| review | 综述单独分组 → `碳+review` (7) |
| micro | → `碳+micro` (231) |
| double-layer | 只搜 double 会漏 Double-shell-structured / double shelled / double buffering carbon layers → 建 `碳+double（双层）`，38 篇逐一浏览删到 36 |
| Rice Husks | 只搜 Rice → `碳+Rice` (17) |
| graphitic | **修饰 carbon 的单词**才是特征词 → `碳+graphitic` (18) |
| Lithiation | 预锂化 → `碳+Lithiation` (51) |
| Simulation | 理论研究 → `碳+Simulation` (8) |
| pouch battery | 去掉 battery → `碳+pouch` (11) |
| P（磷） | 摘要确认 phosphorus → 搜 `P_`（大小写匹配）→ `碳+P\|phosphorus` (14) |

**通适规则**：
> 有的一眼看过去特征词不太明显的文献我们也不用强求一定要从中寻找到特征词，我们可以先略过，先处理容易处理的文献。反正没处理的文献始终留在"碳-未分类"分组中，是不会遗漏的。

**roll vs microroll（不能一味精简）**：搜 roll 会命中 controllable、controlled → 改用 microroll，只得 1 篇。
**double vs double-layer（也不能过分精简）**：见上表。

### 4.2 "父-已分类"组集：批量去除已分组文献

新建组集"碳-已分类"（Create Group Set）→ 把所有二次分组移入 → **点一次即可全选所有已分类文献** → 从"碳-未分类"中去除。

效果数据：2584 → 1020 → 856 → 537 → 235 → 66 → 0。

**重要例外**：`Carbon|C`、`CNF`、`CNT`、`Graphene`、`Graphite` 和"碳"、"碳-未分类"本身**不要**移入"碳-已分类"，否则会把"碳-未分类"清空为 0。

### 4.3 形貌类检索词：like / inspire / Shape / hollow

> 从以上两处下划线部分，我们发现这些和形貌相关的文献，它们都会用到 **like**（表示类似某种形貌的或者某某形状的意思），那么就启发到我们是否可以搜索 like 来批量获取涉及形貌的文献呢（毕竟此类学术论文中，like 大概率不会表示喜欢的意思）？

→ `碳+like`、`碳+inspire`、`碳+Shape`、`碳+hollow`。

形貌分组的 idea 爆发力：石榴形貌 → 西瓜、杨梅、草莓（深入思考西瓜子、瓜瓤、外皮；草莓的分形结构）→ 生物组织形貌 → 不同形貌的对比研究。

**人工智能方式操作的考虑（原话）**：

> 比如我们自己操作的时候，当看到 like、inspire 之类的词，在不看摘要的情况下，我们就会很快得知这些文献是和研究形貌相关的。但是**即使基于大模型的语义理解算法，它也很难把标题中出现 like 的这些文献关联为形貌相关的研究并推送给我们**。

### 4.4 分组到后期：改用中文笼统名

检索词只能获得 1-2 篇时，每个检索词建一个分组不合适 → 用中文名把某一细分领域的文献都囊括进去，即使没有完全一样的特征词：`碳+硅在硅碳复合物中`、`碳+结构-性能`、`碳+特殊结构包覆`。

> 目前阶段的分组或者说文献库标签化操作所产生分组名称或者说标签名称更多的是提供了一个**提示词**的功能，帮助你启发和打开思路，并不代表其中的分组就是特别完整和精确的。

### 4.5 分组名的动态完善

| 原名 | 改为 | 触发文献 |
|---|---|---|
| 碳+Rice | `碳+Rice\|biomass` → `碳+生物质炭` → `碳+炭源` | biomass、waste |
| 碳+failure | `碳+failure\|Degradation` → `碳+失效研究` | Degradation、Aging、Fade |
| 碳+dop | `碳+掺杂` → `掺杂 元素改性` | Nitrogen、Se-Loaded |
| 碳+silicon | `碳+silicon\|Si` → `碳+纯硅` | Si/、Si-、Si_、Si@ |
| GO | `石墨烯` | rGO、Encapsulated |
| binder | `胶粘剂` | enhances adhesion |

- **追加检索词**：`|` 之后放新检索词。
- **中文概括**：不方便继续追加时用，并在分组中新建记录说明形成方式。
- **保留检索词名的理由**：检索词简单、并列不复杂、预计已搜得差不多 → 等处理完再改准确名。

### 4.6 尝试不同排序方式

> 分类到后期，你会发现不太容易找到多篇文献共用的特征词……这个时候你也**不一定非要按照日期排序，你也可以尝试其他排序方式，比如按照 Title（标题）、按照 Journal（期刊）排序**。

- 按标题排序：以 Amorphous 开头的文献集中出现 → 启发搜 Amorphous。
- 按期刊排序：同一期刊收录范围有共性。
- **为什么一开始不用**：担心特征词不够"随机"、带倾向性。前期文献多、容易找特征词，所以要避免倾向性。

### 4.7 反其道行之：给不相关文献建分组

发现某类文献参考价值不大 → 找特征词把它们搜集到一个分组，并从该分组中去除相关文献。执行后要迅速扫一遍标题，把还有参考价值的挑出来。

## 5. 三次分组

### 5.1 触发阈值

> 针对这种某个文献量特别多的某个分组（比如**占据了总文献 20% 左右或更高的分组**），我们会进入这个分组，再次处理下。那至于有些数量不太多（如**占据总文献 10% 左右或更低**）的分组，我们就不再一一处理了，不然工作量太大了。

分档：总文献 6000 多、某分组 1000 多 → 再处理；总文献 1000 多、某分组 200 多 → 可处理到 100 以下；总文献几百篇 → 处理很快，粒度随意。

**机制解释**：相关关键词出现在大分组中、没出现在之后的未分类文献中，按现有处理方式就关注不到了。理发比喻：搜索快速分组像**推剪**，三次分组像**理发剪**精修。

### 5.2 操作要点

1. **先搬走明显归错组的**：在"碳+silicon|Si"中搜 `SiO`（大小写匹配）→ 先全选"碳+硅氧化物"分组 → 从"碳+silicon|Si"中去除；同理去"碳+SiC"。
2. **搜分离词补漏**：`Si-O`（此时不用匹配大小写，因为不太可能有单词包含 si-o）。
3. **取样观察后改名**：不需要看完所有标题，抽查看几个区域，几次取样都相关就认为整个分组基本相关 → 改名"碳+纯硅"。
4. **搜上位词查漏**：在"碳+纯硅"中搜 `oxide` → 67 条 → 发现 Silicon monoxide、silicon suboxides 等同义表达。浏览时**眼神先定位在 Oxide 出现的地方**。
5. **中转组 + 中转组2 双层检查**：67 条全拖入中转组 → 只选硅氧化物相关的拖入中转组2 → 检查后再入目标分组。
   > 一旦直接拖动到"碳+硅氧化物"分组中，由于这个分组中的文献较多，我们就没有办法检查了。
6. **建"X 未分类"避免重复浏览**：`碳+纯硅 未分类` = 只含"碳+纯硅"中未被其它二级分组包含的文献。操作：先全拖入（1247）→ 点"碳-已分类"组集全选 → 去除 → 504 → 点"已分类"组集 → 拖到"碳+纯硅 一级分组中包含" → 去除 → 193。
7. **新建二级分组而非三级**：`碳+Hydrothermal`、`碳+Artificial`。
   > 主要是考虑也许其它非纯硅的分组中也会涉及水热法合成的文献……如果局限在"碳+纯硅"中搜索就会遗漏这部分文献。

## 6. 逐一浏览未分类（极其重要但最容易被跳过）

### 6.1 为什么不能只靠搜索

> 有些特别重要、思考独特深入的文章往往是**比较小众的**，也就意味着我们有时通过搜索获取大批量文献的方式会遗漏这些文献，而这些文章很有可能对你后续的实验或者理论工作开展以及写作有巨大帮助。

包括导入格式问题（Lithium 与 Ion 之间没空格）导致的漏网文献。

### 6.2 工作量论证

- 关键词定位 + 略读 → **平均几秒**一篇；
- 500 篇 → **1 个多小时**；
- 一个硕士/博士整个 2 年半或 4 年，**只要处理这么一个文献库就行了**；
- 属于 **once and for all（一劳永逸）**。

### 6.3 操作规范

1. **固定排序方式**，逐篇浏览不跳跃（否则不知道哪些看过）；
2. **记录看到哪里**（EndNote 定位法）：记当前标题 → 下次在组内搜这篇 → 左栏 Search Results 选中 → 回分组看浅灰色高亮定位；按标题排序可用首字母快速定位；
3. **三种落地方式**：拖入已有分组 / 新建分组 / **笼统分组兜底**；
4. 全部浏览完 → 把"未分类"改名"**已阅 本次不参考**"；
5. **一篇文献贴多个标签**：逐一浏览时一旦分组并从原分组去除，就没机会再从未分类找到它了，所以要考虑多个相关分组。

**笼统兜底分组**：
> 如果每个可参考文献都建立一个分组，会使得标签栏过于庞杂……我们可以建立一个或者几个**名称较为笼统的分组**，比如"碳+可参考"、"碳+重点参考"。

可用：`可参考`、`重点参考`、`1级参考`/`2级参考`/`3级参考`、`尚不了解`、`待分类`、`暂时不参考`、`下全文后分类`。

### 6.4 判断标准

> 如果你略读完整个标题，觉得**无感或者看不懂**的话，就说明这篇文献**没有什么特征的信息能够触发你**，也说明该文献**暂时是跟你做的无关的**。

**光读标题无法分类？真正的原因在【搜】字诀**：

> 我观察的那些说光读标题无法分类的案例，发现他们的问题是出在上一步的【搜】字诀……比如相关度是**低于 20% 甚至 10%**，那这就意味着导入到文献库中的文献可能高达 80% 都是不相关的。

## 7. 非排他标签化（与排他性分组的抉择）

### 7.1 指数爆炸论证

排他式（每篇只在一个组，想看第 2 个标签就要做二级分组，第 3 个就要三级）：

```
碳+纳米、碳+多孔、碳+掺杂、碳+纯硅+纳米、碳+纯硅+纳米+多孔、碳+纯硅+纳米+多孔+掺杂、
碳+硅氧化物+纳米、碳+硅氧化物+纳米+多孔、碳+硅氧化物+纳米+多孔+掺杂、
碳+硅合金化+纳米、碳+硅合金化+纳米+多孔、碳+硅合金化+纳米+多孔+掺杂   → 12 个
```

非排他式只需 **6 个**：`碳+纯硅`、`碳+纳米`、`碳+多孔`、`碳+掺杂`、`碳+硅氧化物`、`碳+硅合金化`。

> 你自己知道这些分组间是存在**排列组合**关系的，你可以自行组合。如果你后期研究方案更进一步细化了，你需要进一步限定分组范围，那么继续加上第 3 个标签也不迟。

### 7.2 搜索范围一直最大化

> 采用我们目前这种分组方式，我们用于搜索的文献数量其实一直没有减少，一直是最完整的文献数……所以我们每次的搜索范围都是最大化的，只要包含这个标签的文献都会被囊括在对应分组中。

### 7.3 何时可用排他性

> 有时你会遇到你关心的领域，文献数量较少，而且文献之间交集不多，那么也可以尝试完全排他性的分组……**每次搜索的时候从未分类文献而不是从总文献库中搜索**即可。

更简便方式：建库时不建立任何分组囊括总文献，所有文献都在 EndNote 自带的 **Unfiled 栏**，直接从 Unfiled 搜索分类。

文科案例（96.pdf）就是排他性分组：已明确要做"汉语言文学 + 社会化阅读"，直接拿最相关文献，不足再处理未分类。

> 和之前俯瞰型的文献库分组（贴标签）方式相比，这种方式显得更直奔主题。

## 8. 高频错误（务必先读）

| 错误 | 根因 | 正解 |
|---|---|---|
| 觉得吞进来的文献必须全部分完 | 为分类而分类 | 分组是为了获得 idea；分不完就放着 |
| 标题看不懂就要下全文 | 把弱相关当目标 | 看不懂的放一边，可能就是鲸吞进来的不相关文献 |
| 几百篇看不懂想批量下载全文 | 同上 | 建立"下全文后分类"分组，暂缓 |
| 第一轮就追求精准 | 误解鲸吞法 | 相关度 >40% 即启动 |
| 用词频统计工具自动分组 | 见 §9 | 分组名要有语义而非词频 |
| 分组名不带父分组前缀 | 易混淆（案例中有两个 dop 分组） | `父+检索词`，`+` 表示同时满足两个条件 |

## 9. 为什么不用词频统计工具

86/94.pdf 的五点论证：

1. **统计规则不透明**：不具实体意义的词也会被统计出来（如 property）；
2. **搜不到关键符号**：表示包覆的 `@` 很难被识别统计；
3. **词干/词元被切碎**：nanoparticle、nanowire 的 nano 一般不会被统计出；
4. **同义表达割裂**：失效/原理方面的不同表述无法被归为同一细分领域；
5. **漏掉小众重要文献**：没有共性表述的重要文献被忽略。

> 比如同样是性能，根据我们前面的讨论，我们会把 rate 作为一个搜索和分组词，那么看了这个分组名称我们就知道："哦，这些文献应该是研究倍率的"……但是如果将更高频的 property 作为分组词，其实我们就不知道这些文献到底是研究什么的。

> 只要对照着本书的分析，一边看一边结合自己的文献库操作，你会发现基本**一个半天就全部处理完毕了**，但如果借助程序和可视化工具……最后耗费的时间**远远超过一个半天**。

> 比如有位同学关注 like……就算提取了 like，**它能关联到这是形貌研究么**？**能分出组和能分出为你后续研究和论文发表提供参考的分组是完全不同的概念。**

## 10. 何时扩到摘要搜索

| 情形 | 是否扩摘要 |
|---|---|
| 标题搜索已得成百上千篇 | **不扩**（除非找不到 idea / 做不出实验 / 写不出论文） |
| 标题搜索只得十几~几十篇 | 扩 |
| 文献库总量只有几百/几十篇 | 扩 |
| 开始制定具体研究方案后 | 针对特定分组扩，并在分组中加记录 |
| 换位思考 | 如果某个点对你重要，你会把它放到标题里；标题没出现，说明作者认为别的内容更重要 |

EndNote 操作：检索范围可从标题改为摘要；检索时要"同时囊括标题和摘要"。

**理论研究检索的特殊解法**：标题不体现、摘要有 `mathematical model` → 分别搜 `math` 和 `model`（词根化），检索范围同时囊括标题和摘要 → 建 `math`、`model` 分组 → 再扩 `theor`。建立**同义表达表单**，把看到的同义表达先记下来，随后统一搜索。

## 11. 读摘要的信号词读法

**什么时候看摘要**：看不懂缩写/专有名词（rGO、Encapsulated、Si-O-C、P）；确认分组归属（CNF、SiO）；判断是否值得建组（shell、dop）；了解分组背景。

**读法（下划线标注法）**：
- 第 1 句看 `Silicon`、`still limits`、`due to` → 作者认为的优势、问题和原因；
- 第 2 句看 `Despite`、`the challenges including` → 现状/优势与仍存在的问题；
- 非下划线部分快速略过；
- `First`、`Second` 之后是展开具体研究内容，可快速略过；
- 摘要头两句话通常足以获得背景。

**读摘要的时机**：

> 我们现在不是处于一个信息缺乏而是信息非常泛滥的时代……如果每个信息都不假思索地一看到就浏览，可能一生用于阅读信息都不够，所以我们需要尽可能的降低盲目摄取信息的操作。

> 我们是**先尽量根据标题（不行的话，再扩展到摘要和全文）选出觉得可能需要读的文献**，但是到了有必要的时候，比如**到了需要制定研究方案或者写作的时候才开始进入正文去读**。

**货比三家**：不要看到第一篇认为不错的文献就立即精读；先把可参考文献汇总，再根据当前目标投入精力读。

## 12. 分组的复利效应与 idea 涌现

> 随着文献库中的分组增多、分组中的文献增多……**在你甚至还没开始阅读文献正文的过程中，对这个领域的认知已经提升上来了**。认知提升后，你会发现很多文献其实没必要去阅读……还有一些文献，你甚至可以在摘要都不需要去看的情况下，也大概知道他在讲什么事情。

**二级分组俯瞰 → 研究方案雏形自检清单**（案例）：
- 碳材料可以如何制备（生物质炭/废弃物/其他方法）？
- 碳需要做什么形貌（光滑均匀覆盖 / 珊瑚状触角）？
- 纯碳就行么，是否需要掺杂？
- 被碳包裹的硅选什么体系（纯硅/硅氧化物/合金）、多大（微米/纳米）、什么形貌（0D/1D/2D/3D；实心/多孔/空心）、如何制备？
- 用哪些方法表征？
- 胶粘剂、电解液、正极是否需要特别考虑？
- 要达到什么目标（循环寿命、首效）？是否关注倍率、热稳定性？
- 失效后做哪些分析，如何关联性能与结构？
- 制备方式可否规模化？

> 在没形成这些二级分组之前，我们是完全没有这些概念的，而现在我们对于研究方案的大概雏形也有了，更重要的是，以上思路也不是我们绞尽脑汁凭空想出来的，而是**自然而然涌现的，都是源自某些标签的提示**。

**自我校验标准**：
> 刚开始对自己要做什么，发表什么论文，是感到**茫然和一片空白**的。但随着操作的进行，这些空白处先是出现了**隐约的轮廓**，随后轮廓越来越清晰。

## 13. 停止时机与退回

**停止标准**：
> 关于分组到什么程度或者分组中的文献数量减少到什么程度就停止分组**没有标准答案**……只要你觉得目前的分组颗粒度可以帮助你启动下一步操作（即启动实验和/或理论研究），你就可以暂停分组了。

**可以随时退回**：
> 每一个操作，并不是单线程的关系，它是**可以随时返回后退操作**的，而且这种返回操作不会让你前期的工作白费……甚至我们还可以**退回到先前的【搜.鲸吞法】步骤中，重新构建检索式，增量导入新的文献**。

**问题优先级**：不着急且复杂度不随时间增加的问题，推迟到必须解决时再处理——认知提升后更快，有时问题会自己消失。
